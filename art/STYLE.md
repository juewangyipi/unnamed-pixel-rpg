# 美术风格规范 · 档位 B

> 参考：《潜水员戴夫》气质（鲜艳、卡通、有纵深）× 本游戏俯视奇幻冒险  
> 色调：戴夫海感青蓝 + 北欧草地 混合

## 总则

| 项 | 规格 |
|----|------|
| 基础格 | **32×32** px（建筑可更大：shop/warehouse 64、house 96×72） |
| 透视 | **俯视**（不是侧视潜水） |
| 描边 | 深色 1px 外轮廓，邻接透明处；`ink` 略带青紫而非纯黑 |
| 阴影 | 脚底椭圆；偏冷色半透明（`rgba(8,24,40,0.28)`），陆地也带一点「戴夫光」 |
| 层次 | 地砖 → 小路 → 装饰/建筑 → 可互动物 → 角色；水面可闪烁 |
| 导出 | PNG 进 `beta0.01/public/assets`；ASE 进 `art/ase` 供 LibreSprite 手改 |

## 色板（主）

### 海感青蓝（戴夫向）

| 用途 | 近似 RGB |
|------|----------|
| 水深 | `#0e3a52` `#145a78` |
| 水中 | `#1e88a8` `#3ab0c8` |
| 水亮/泡沫 | `#7ad4e8` `#c8f0f8` |
| 布料/披风 | `#1a5a72` `#2a88a0` `#4eb8c8` |

### 北欧草地

| 用途 | 近似 RGB |
|------|----------|
| 草深 | `#2a5a38` `#3a7848` |
| 草中 | `#4c9858` `#68b868` |
| 草亮/叶尖 | `#8cd878` `#b0e890` |
| 略偏青的草影 | `#2a6050`（接水色） |

### 木石与暖色点缀

- 树干/木板：暖褐 `#3a2818` → `#c4a06a`
- 屋顶：砖红略饱和 `#8a3030` → `#d87858`（村落亮点）
- 皮肤：暖 `#e8c8a0`；头发深褐
- 金属/腰带：金 `#e0c060`

## 角色

- 比例：略圆润、头偏大（卡通可读），脚底对齐 32 格底边
- 服装主色：**海青披风/背心**，金扣腰带（呼应戴夫潜水服青系，又像奇幻旅人）
- 表情：正面双眼清晰黑点 + 高光；侧脸一眼
- 四向：`player_down/up/left/right.png`

## 地形

| 砖 | 要点 |
|----|------|
| `tile_grass` | 北欧绿为主，偶有青影与小花 |
| `tile_village` | 草 + 青灰石板（村落 cobble） |
| `tile_path` | 暖土石径，边缘略深 |
| `tile_water` | 青绿波纹 + 高光点（戴夫海） |
| `tile_water_edge` | 左草/径 → 右水 |
| `tile_forest` | 更深绿褐落叶 |

## 初始村子优先

1. `tile_village` + `tile_path` 横贯
2. `house` 中心大屋（窗玻璃用海青高光）
3. `bush` 院落四角
4. `shop` / `warehouse` / `save_point` 与角色同色系

## 档位 B+ 渲染（代码）

- 地砖：主/副变体交错 + 偶发水平翻转
- 装饰：Y 排序绘制 + 脚底双层阴影
- 氛围：天光双层、侧向斜光、vignette、村落路径暖带与屋后薄雾
- 水面：焦散斑点 + 岸线泡沫 + 深水渐变
- 微粒：花粉/尘埃漂浮
- 角色：行走微弹 + 阴影压扁
- 昼夜：已有压暗与光源挖洞

## 工作流

```bat
python art\generate_sprites.py
```

再批量转 ASE（可选）：

```bat
for %f in (art\src\*.png) do LibreSprite\libresprite.exe -b "%f" --save-as "art\ase\%~nf.ase"
```

手改：`LibreSprite` 打开 `art/ase/*.ase` → 导出 PNG 覆盖 `public/assets`。
