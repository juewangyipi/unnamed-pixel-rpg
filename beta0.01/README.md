# Game beta0.01

网页单机 · 俯视像素 · 开局可玩垂直切片。

**版本策略：** 当前为 **beta0.01**（玩法/系统试做）。有更完整的正式故事背景后，再升到 **v0.1**。  
架构构思仍见上级目录 `第一版架构_v0.1.txt`（文内历史 “v0.1” 指首个垂直切片范围）。

工程目录：`beta0.01/`（与对外版本号一致）。

## 技术

- Vite + TypeScript + Canvas 2D
- 本地存档：`localStorage`（键 `game-beta0.01-save`）
- 像素资源：`public/assets/*.png`（源文件与 LibreSprite 工程见上级 `art/`）

## 开发

```bash
cd beta0.01
npm install
npm run dev
```

## 四图

```
        森林
         │
草地 ── 村落
         │
       河边
```

| 地图 | 内容 |
|------|------|
| 村落 | 商店、仓库、篝火、存档点、出生 |
| 草地 | 过渡 · 有树 |
| 河边 | 鱼点（生虾） |
| 森林 | 树 |

## 操作

| 键 | 作用 |
|----|------|
| WASD / 方向键 | 移动 / 切屏 |
| E / Space | 设施点按 · 采集点一下持续 · 篝火点/灭 |
| B / I | 背包 |
| Esc | 关闭面板 |
